```html

```
脚本开头照样张写这几样:
```js
const SEG = { 1: 0, 2: 2.45, 3: 3.8 /* … 抄段表的 t0 */ };
const SH = {   // 截图:size / boxes 照抄 assets/shots/*.json,不要自己量像素
  gh: { src: "assets/shots/gh_repo.png", size: [2880, 1800], boxes: { title: [0.1, 0.2111, 0.0604, 0.0256], star: [0.8432, 0.2089, 0.079, 0.0311] } },
};
const shot = (k, o) => K.shot(o.par, Object.assign({}, SH[k], o));
const O = (i) => [(i - 1) * 3200, i % 2 ? -40 : 50, -((i - 1) % 3) * 140];          // 每段一个布景原点
const ARR = (i) => (i === 1 ? 0 : SEG[i] + 0.45);                                      // 镜头到位时刻
sp.shots(Object.keys(SEG).map(Number).map((i) => ({ t: ARR(i), d: 0.5, at: O(i), dist: 1600, yaw: YAW[i], pitch: 2, focus: 100, ap: 7 })));
const Lr = (i, sx, sy, dz, q = {}) => { const p = sp.place(ARR(i) + 0.01, sx, sy, dz); return sp.layer(Object.assign({}, q, { x: p[0], y: p[1], z: p[2] })); };
```
`Lr(段, 屏幕x, 屏幕y, 前移)` = 「这一段镜头到位时,出现在屏幕 (x,y) 的图层」,前移就是景深层(第五节)。

## 二、动画库存(公共库 `engine/web/hz_kit.js`,版本 `hz.k.v`)
每个动画都按绝对时间计算,同一时刻永远是同一画面。凡是「交互」都会记进 `hz.k.log`,`hz check` 用它核对段表要求的交互有没有真的做。

| 动画 | 调用 | 用在 | 默认时长 / 节奏 | 缓动 | 放哪层 | 段表 kind |
|---|---|---|---|---|---|---|
| 截图窗 | `K.shot(par,{src,size,w,crop,boxes,r})` | 所有真实截图 | —(出场用 `T.pop`) | — | 中景 | (素材) |
| 框选扫过 | `K.frame(par, 区域, {t0,d,t1,label,labelAt,sweep,breathe,dim})` | 点名截图上的某块 | 描边 0.45 s → 扫光 0.6 s → 呼吸周期 1.5 s;标签在 t0+0.7·d 浮出 0.25 s | 描边 stop,扫光 inout | 跟截图同层 | `frame` |
| 高亮脉冲 | `K.pulse(par, 区域, {t0,n,gap,d,grow})` | 收尾点按钮、星标 | 2 圈,每圈 0.7 s,间隔 0.32 s,放大 35% | out | 跟截图同层 | `pulse` |
| 计数跳动 | `T.count(el, 0, 终值, t0, d, {sep:true})` | Star 数、下载量 | 0.6–0.9 s | 引擎默认 | 前景 | `count` |
| 终端逐字 + 完成行 | `hz.w.terminal(par, [{cmd, at, cps, out:[{s, ok:true}]}], {title, rows})` | 安装、运行命令 | cps 30–40,回车 0.25 s,输出 0.2 s 后出现 | — | 前景 | `terminal` |
| 浏览器 spinner→内容 | `K.browser(par,{w,url,typeAt,cps,load:[l0,l1],src,size,crop,boxes})` | 打开网页、动态加载 | 地址栏 cps 26–34;加载 0.5–0.8 s;内容去虚浮入 0.4 s | 进度条 out,内容 stop | 中景 | `load` |
| 改版前后闪切 | `K.swap(par,{before,after,at,back,t0,w,h,labels,mode})` | 前后对比 | flash 0.12 s / wipe 0.55 s,切换时整体轻弹 2.5% | out / inout | 前景 | `swap` |
| pills 逐项点亮 | `K.pills(par, 项[], {t0,at,gap,size,w})` | 能力清单、支持列表 | 每项入场错开 0.05 s;点亮间隔 0.16–0.2 s,打勾 0.28 s | 入场 stop,点亮弹簧 | 前景 | `pills` |
| 代码逐字 + 行高亮 | `K.code(par, 行[], {title,t0,typeAt,cps,hl:[{line,at,d}],light,size,w})` | 示例代码、HTML 片段 | cps 30(短代码可到 80);高亮横扫 0.35 s | stop | 前景(主角)/ 中景 | `code` `hl` |
| 面板滑入 | `K.panel(el, t0, {from,dist,d,t1})` | 侧边面板出场 | 0.55 s,位移 140 px,带 6 px 运动虚化 | stop / 滑出 in | 任意 | 不算交互 |
| 鼠标点击路径 | `hz.w.cursor(par, [{t, x,y 或 el, d, click}], {t0,t1})` | 点按钮、点菜单 | 每段移动 0.7 s 弧线,点击缩一下 + 圆环 | — | 前景 | `click` |
| 列表逐项打勾 | `hz.w.list(par, 项[], {t0,at,gap,cols})` | 文件列表、步骤 | 间隔 0.18 s | — | 前景 | `list` |
| 结果行弹出 | `hz.w.results(par, [{k,v,ok}], {t0,gap})` | 输出结果 | 间隔 0.16 s | — | 前景 | `results` |
| 进度条 / 输入框 / 按钮 | `hz.w.progress` / `hz.w.input` / `hz.w.button` | 流程演示 | 见 UI3D.md | — | 前景 | `progress` `input` `click` |
| 满幅暗场 | `K.dark(sp, [[t0,t1]], {fin,fout})` | 转折段、反爬这类「狠话」段 | 淡入 0.35 s,淡出 0.4 s | inout | 屏幕空间(sp.bg) | 不算交互 |
| 区域换算 | `K.rel(区域, 从元素, 到元素)` | 把框选/标签挪到不裁切的外层 | — | — | — | — |

**勿出画**:所有动画的元素(包括框选标签、脉冲放大后的圈、滑入的起点)在动作期间都不能超出画面 30 px 安全边;`hz check` 会查文字,圈和框要自己算(脉冲放大 35%,框外留 ≥0.2 倍区域宽)。

## 三、假窗结构(HTML/CSS)
颜色只用色板变量;四种假窗都带 class `hz-ui`(检查器靠它量「画面上有多少 UI」)。

| 假窗 | 结构 | 要点 |
|---|---|---|
| 截图窗 `.hz-k-shot` | `div.hz-k-shot > img`(img 按 crop 偏移,外层 overflow:hidden 裁切) | 圆角 14,细描边 + 下投影;`root.box("名字", 外扩)` 给出区域像素 |
| 浏览器 `.hz-k-br` | `.bar`(三个圆点 + `.url` 锁形图标 + 地址 + `.pg` 进度条)→ `.body`(`.ct` 内容、`.sk` 骨架屏、`.sp` 转圈) | 地址栏高 48;内容 = 真实截图(`src`)或自己的元素(`content`);**不许只有骨架和转圈就结束** |
| 终端 `.hz-w-term` | 标题栏(三个圆点 + 标题)→ 行 `.ln`(`$` 提示符 `.pr`、命令 `.cm`、输出 `.ok` 成功 / `.er` 报错) | 宽度在本期 `<style>` 里写:`.hz-w-term{width:700px} .hz-w-term .ln{font-size:24px}` |
| 代码块 `.hz-k-code` | `.hd`(三个圆点 + 文件名)→ `.bd` → 每行 `.ln`(`.hl` 高亮条、`.no` 行号、`.cd` 代码) | 深色(默认)或 `light`;`root.line(n)` 给出第 n 行区域,可直接框选 |
| 卡片面板 `.hz-card` | `hz.card(par,{w,title,sub})` → 内容放 `card.body` | 放输入框、按钮、结果行这类流程演示 |

## 四、框选规范
- **坐标只用截图 `.json` 的 `boxes`**(0–1 比例):`s.box("名字", 外扩px)` 换成像素。不要估像素。
- **颜色**:`--k-frame`(默认 = `--c-accent`),标签底色同色、字 `--k-frame-ink`(白)。描边 3 px、圆角 10、外扩 8。
- **节奏**:描边 0.45 s 画完 → 扫光扫过一次 → 外发光呼吸(1.5 s 一个周期)。同一画面**最多 2 个框同时亮**;下一个框出现前用 `t1` 收掉上一个(样张段 8)。
- **压暗**:`dim: 0.3` 只在会裁切的父元素(截图窗、浏览器)里用,让框外变暗。
- **标签**:中文 ≤8 字、英文 ≤14 个字母,写事实不写形容词;位置 `labelAt` 默认自动(上/下/框内)。标签会挡住页面重要内容时,把框挪到外层(`K.rel`)并用 `left`/`right` 放到截图外面。
- **截图要大**:框住的区域在成片里至少 30 px 高、字能读清;做不到就把 `crop` 裁小、`w` 放大(样张段 2 只裁仓库页的一条,1200 宽)。

## 五、景深约定
| 层 | `Lr` 的前移(dz) | 放什么 | 处理 |
|---|---|---|---|
| 前景 | +200 ~ +260 | 标题、终端、代码块、pills、浏览器(当它是主角时) | 焦点常在这里 |
| 中景 | 0 | 截图窗 | 镜头 `focus` 写 100 左右,让前景和中景都清楚 |
| 背景 | −700 左右 | 弱化的 UI、上一话题的截图、巨大淡字 | `layer.dofK = 1.5–2` 加虚,截图透明度 0.6,淡字 0.07 |

- 文字**挂在所属的层上**:框选标签是截图层的子元素,跟截图一起动;标题是自己的前景层。
- 每段至少两层;**不许全部放在 dz 0**。
- 透明度写在内容元素上(如 `shot(...).style.opacity = 0.6`),**不要写在图层 `.in` 上**——`T.pop` 会把 `.in` 的透明度覆盖掉。

## 六、转场、暗场与底板
- **暗场只用 `K.dark`**:它铺在 `sp.bg`(屏幕空间,在所有 3D 图层后面),无论镜头怎么转都满幅,淡入淡出整屏一起变,**不会露出纸底竖缝**。暗场里的标题改用 `color:var(--c-card)`。
- **不要在世界空间铺「黑底板」**:引擎会把锚点投影离画面中心超过 1.6 倍画宽的图层直接隐藏,大板会在飞行途中突然消失 → 竖缝(v2、v5 的竖缝就是这么来的)。
- 世界空间里的板只要刚好盖住镜头:该深度能看到的宽度 ≈ 画面宽 ×(镜头距离 − z)/ 1600。镜头距离 1600、z = −700 时约 1.44 倍画宽(1920 → 约 2760)。最长边 ≤ 4000 px;比画面大的板 `dof:false`。
- 纸底由 `hz.space` 自带,不需要也不要自己铺。

## 七、时间规则(检查器会查)
- 镜头:每段 `t0 − 0.05` 起飞,`t0 + 0.45` 到位(飞行 0.5 s)。
- **每个元素完整出现后至少 0.6 秒才能被飞镜甩走或虚掉**:一段里最后一个元素必须在「下一段 t0 − 0.65」之前完整出现。来不及就让它提前出,或删掉。
- 上一段的东西在下一段 t0 统一虚掉:`outAll([图层…], 下一段t0)`(blur 0.25 s)。
- 交互动画的时刻对准段表的 `at`(段表的 `at` 又对准口播关键词读音)。

## 八、音效挂钩(只做音效,不做配乐)
- `bin/hz plan <本期> --sfx` 按段表生成 `03_sfx.json`:**每段起飞一声 whoosh(段 t0 − 0.05)+ 每个交互在它的 `at` 响它的 `sfx`**;`keytap` 自动连敲 8 下(间隔 0.085 s)。已有 `03_sfx.json` 时加 `--force` 才覆盖。
- 默认音量:whoosh 0.3 · thump 0.45 · tick 0.38 · keytap 0.2 · pop 0.38 · chime 0.32 · shimmer 0.28 · swish 0.3。
- 推荐搭配:框选 `tick`、计数 / 弹出 / 加载完成 `pop`、终端和代码 `keytap`、前后闪切 / 行高亮 `swish`、收尾脉冲 `chime`、重音落字 `thump`。
- 页面里的时刻改了,就改段表的 `at` 再重新生成,两边保持一致。然后 `bin/hz sfx <本期>` 混音。

## 九、性能上限(MacBook Air · M5 · 16 GB)
- 同一时刻可见的图层建议 ≤6 个,带景深虚化的 ≤3 个(样张每段 3–4 个)。
- 截图显示宽度一般 800–1500 px;原图用 2 倍截图(2560–2880 宽)已足够,不要更大。
- 大面积 `filter: blur` 最吃性能:大板不加景深,背景层只放小尺寸弱化 UI。
- 检查:改一段只查一段(`--from/--to`);交渲染前跑一次全片;**不要边渲染边检查**;渲染 `--workers 4`。

## 十、检查流程
```bash
bin/hz check <本期> --from 13 --to 17   # 改了段 6,只查这一段
bin/hz web_render <本期> still 9.0 16.6  # 可选:看一两个关键时刻有没有明显错误(不反复打磨)
bin/hz check <本期>                      # 交渲染前:全片检查(27.6 秒的片约 12 秒)
bin/hz web_render <本期> final --workers 4
```
全片检查会打印每个案例段的画面构成,例:`段4 UI 94% 交互 2/1`= 这段 94% 的帧里 UI/截图占画面 ≥18%,做了 2 个交互(段表要求至少 1 个)。

## 十一、已知的坑
| 现象 | 原因 | 怎么办 |
|---|---|---|
| 深色底上的字看不见(深色纸片、深色代码块、自己写的深色面板) | `hz_canvas.js` 给所有 `.hz-txt` 写死了墨色 | 动画库已修好代码块和 `T.chip({dark:true})`;自己的深色容器加 `.我的容器 .hz-txt{color:inherit}` |
| 元素莫名跑到父元素中间 | `hz.css` 有全局短类名:`.c`(绝对定位到 50%)、`.sc` `.p3` `.mono` `.node` `.ch` | 自己的元素不要用这些类名 |
| 代码缩进没了 | `.hz-txt` 是 `nowrap`,会合并连续空格 | 代码块已改成 `white-space:pre`;自己写的代码也要加 |
| 终端成功行是橙色(像报错) | `hz_ui3d` 终端成功行用 `--c-accent` | 动画库已改成主色;要别的颜色写 `--k-ok` |
| 暗场露竖缝 / 底板突然消失 | 世界空间大板被视野裁剪隐藏 | 用 `K.dark`;底板按第六节算大小 |
| 框选标签挡住截图里的标题 | 截图窗会裁切,标签只能放框上下 | `K.rel` 把框挪到外层,`labelAt:"left"/"right"` |
| 透明度设了没效果 | `T.pop` 覆盖了 `.in` 的透明度 | 写在内容元素上 |
| 截图太小看不清 | crop 太大、显示宽度太小 | 裁小、放大(第四节) |
| 页面打不开、渲染超时 | 脚本有语法错误,页面没就绪 | 看浏览器报错;注意单行代码里别插 `//` 注释把后半行注释掉 |
