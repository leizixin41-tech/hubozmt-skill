# 素材库 · 调用规范

> 本规范由 Claude 制定(用户授权:素材来源与整理方式由我设计)。目标:以后遇到相似内容,先查库、能复用就复用;每个素材都说得清**从哪来、能不能商用**。视频要发自媒体平台,侵权风险必须在入库时就挡住。

## 一、目录
| 文件夹 | 放什么 |
|---|---|
| `图片/` | 摄影、插画、纹理、背景图 |
| `界面与截图/` | 软件界面、网页截图、对话框、面板 |
| `图标与标志/` | 应用图标、Logo、功能图标(带透明通道优先) |
| `抠图/` | 已经抠好的透明 PNG 或遮罩 |
| `视频片段/` | 可用的实拍/屏幕录制片段(≤30 秒为宜) |
| `AI生成/` | 用户以后接入图像模型生成的素材(必须记提示词) |
| `参考-仅看不用/` | 只用来学习的材料(官方演示视频等),**绝不剪进成片** |
| `索引.json` | 全部素材的登记表 |
| `assetlib.py` | 查询/入库接口 |

## 二、取用顺序(做视频缺素材时)
1. **先查库**:`find(tags=[...], kind=..., commercial_ok=True)`。
2. 库里没有 → **网上找**:优先官方仓库/官网/官方媒体包;其次明确写着可商用的图库(CC0、Unsplash 许可、Pexels 许可等)。找到后先看授权再下载。
3. 还没有 → **AI 生成**(用户计划接入图像模型接口):先写提示词清单(用途、比例、光向、留白位置、不要出现的内容),生成后入库并记录提示词、模型、种子。
4. 实在没有 → **用代码自制**(几何、界面还原、图表等)。

## 三、入库规则
1. **一定要登记**(`add(...)` 会自动写索引)。不登记的文件不算素材库的一部分。
2. 必填:`标签`(至少 3 个,中文)、`来源`(网址或「自制」)、`来源类型`、`授权`、`可商用`。
3. **可商用三档**:
   - `是`:授权文字明确允许商用(MIT / CC0 / 平台许可 / 自己生成并且模型条款允许)→ 可进正式成片;
   - `待确认`:作者没写授权 → **只能用在草稿,发布前必须确认或替换**;
   - `否`:明确禁止 → 不得使用(放进「参考-仅看不用」)。
4. **AI 生成素材**(libTV 等)必须记录:`提示词`、`模型`、`种子`/任务号、所在画布,并核对该模型的商用条款;用到真人/商标/公众人物的图像一律不入库。
5. **不覆盖**:同名文件不覆盖;修改版另存,并写 `衍生自`。
6. 原图保留原始分辨率,不压缩;缩略/裁切在代码里做。

## 四、命名
`<类别>_<主题>_<序号>[_<尺寸>].扩展名`,例如 `摄影_橙色花朵青绿背景_01.png`、`compositor_应用图标_01_1024.png`。标签里写**内容**(花、橙色、人像)、**风格**(暗调、电影感)和**可用方式**(适合抠图、留白在右)。

## 五、使用规则(成片里怎么用)
1. **抠图必须从真实图片算边缘**,不用圆或多边形去假装主体轮廓。
2. **版权标注**:成片里用到「待确认」素材时,Claude 必须在交付说明里列出,不得悄悄混进正式版。
3. **来源可追溯**:每支片交付时附一份「素材清单」(自动由使用记录生成)。
4. **不编造**:用到的数据、评价、截图必须真实;概念画面要标明。

## 六、现有入库说明(2026-10-20)
