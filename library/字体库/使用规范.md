# 字体库 · 使用规范

> 本规范由 Claude 制定(用户授权:字体自行选择、自行下载,**前提:免费且允许商用**,因为视频要发到自媒体平台)。
> 所有字体都登记在 `字体清单.json`(授权、来源、用途)。授权文件(OFL.txt 等)就放在各字体文件夹里。

## 一、入库规则(新增字体前必须满足)
1. 授权必须是 **SIL OFL / Apache 2.0 / 同等「可免费商用」许可**。拿不准授权的,不下载。
2. 来源优先级:Google Fonts 仓库 `google/fonts`(`ofl/` 目录)> 字体作者官方 GitHub Release > 其他。
3. 下载后立刻放进以字体名命名的文件夹,**连同授权文件一起放**,并在 `字体清单.json` 里登记(授权 / 来源 / 用途 / 日期)。
4. 以下一律**不入库**:授权写着「仅个人使用/非商用」的字体;来源不明的字体(比如各种「免费下载站」的字体);带水印或被改名再分发的字体。
5. 保留字体名(Reserved Font Name,如霞鹜文楷、得意黑):用它们做视频完全可以;**不要把改造过的字体文件改个名字再发出去**。

## 二、调用规则(代码里怎么用)
- **只能通过「角色」调用**:`from fontlib import face` → `face("serif", 120, 700, ch="项")`。场景里不许直接写字体文件路径。
- 角色表(每个角色同时定义了中文字体和拉丁字体,保证中英混排时风格一致):

| 角色 | 中文 | 拉丁 | 气质 | 用在哪 |
|---|---|---|---|---|
| `sans` | 思源黑体 | Inter | 中性、清晰 | 界面还原、解释句、小字(默认) |
| `serif` | 思源宋体(可变 200–900) | Fraunces(可变) | 编辑、杂志、有分量 | 安静的大关键词、引文 |
| `serif2` | 思源宋体 | Instrument Serif | 细长、优雅 | 极简的大字、斜体点缀 |
| `hand` | 霞鹜文楷 | 霞鹜文楷 | 人文、温暖、像手写 | 说明句、旁白式短句 |
| `punch` | 站酷庆科黄油体 | 同左 | 重、海报、冲击 | 1–4 个字的冲击词(「太离谱了」) |
| `oblique` | 得意黑 | 同左 | 动感、科技、倾斜 | 速度、并行、动作类短词 |
| `grot` | 思源黑体 | Space Grotesk | 几何、利落 | 英文品牌词、数字 |
| `bric` | 思源黑体 | Bricolage Grotesque | 松弛、有个性 | 拉丁标题要「有点性格」时 |
| `mono` | 思源黑体 | JetBrains Mono | 技术、等宽 | 网址、代码、数据 |

## 三、搭配
字体怎么搭配由设计师按画面内容自由决定,这里不设固定规则。只有两条底线:
1. 渲染前对每段文字调用 `has_glyphs(role, text)`,缺字就换一个角色,成片里不允许出现方块字。
2. 只用本库里的字体(授权已核对过)。想用新字体,先按「一、入库规则」入库。

## 四、文件清单约定
- 每个字体一个文件夹:`字体库/<字体名>/`,里面是字体文件 + `OFL.txt`。
- 不在系统里安装这些字体,只由 `fontlib.py` 读取,避免污染用户电脑。
