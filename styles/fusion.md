# 风格档案:fusion(融合版,2026-10-24 起由 space3d 取代默认)

来源:用户 2026-10-21 定的方向——把「compositor-v1 无限画布 + 文字动效」(用户认定的最佳版本)和「uiverse 那期的 3D 透视 + UI 交互」(用户很满意)融成一种。
引擎:浏览器(`engine/web/`),30 帧。

## 气质一句话
一张深色电影感的**无限画布**是骨架,镜头在上面飞行讲故事;讲到功能、操作时,镜头**扎进**画布上的一张卡片,卡片立起来带 3D 透视,做真实的 UI 交互演示,演示完**放平落回画布**,镜头继续飞。

## 骨架(不能变)
- 整片在一张画布上,每段内容是画布上的一个位置;镜头飞行(缩放 + 平移弧线,中途略拉远,快起慢停)。
- 讲过的内容**虚化 + 压暗 + 降饱和 + 微微后退**,当前内容最亮最清楚。
- 背景暗色、虚化,不抢内容;每段身后可有一团很淡的彩色光斑,随镜头换色。

## 两种段落
| | 画布段 | 3D/UI 段 |
|---|---|---|
| 用在 | 观点、概念、关键词、数字、转折、结论 | 功能演示、操作流程、界面、命令行、结果展示 |
| 画面 | 平面画布 + **关键词文字动效**(核心模板) | 卡片立起来带透视 + **UI 交互动画** |
| 动效 | 逐字上浮、光标擦出、打字、数字滚动、荧光笔、胶囊标签… | 输入、按钮回弹、加载、逐行结果、逐项打勾、终端、进度条、鼠标点击… |

- **比例:3D/UI 段占全片 50%–60%**(按时长算)。但每段 3D/UI 都要从画布进、回画布出,整体感受始终是「一张画布在讲故事」。
- 交替出现:同一种段落不连续超过两段。
- 3D/UI 段里也可以叠关键词文字动效(比如卡片旁边一个大字),层级仍是关键词最先被看到。

## 衔接(两种段落之间必须用,不硬切)
- **扎进卡片**:镜头推近画布上的卡片,卡片立起、前移、放大到占画面约 70–85%。
- **卡片放平**:演示完卡片转回平面,缩小落回原位,镜头拉开飞向下一段。
- **画布倾斜飞行**:整张画布带一点 3D 角度飞行,用在需要空间感的地方(拉远回看全部内容、段落大转折)。
- 画布段之间照常飞行。

## 颜色(保证不跑调)
- 每期一套色板,4–5 个颜色:`--c-bg` 底、`--c-ink` 主文字、`--c-mute` 次要灰、`--c-main` 主色、`--c-accent` 辅色、`--c-warn` 警示(只点缀);卡片 `--c-card`、描边 `--c-line`。
- **画布、文字、UI 卡片、3D 场景全部只用这套颜色**;截图类素材做成卡片时加统一的圆角、投影、细亮边,让它融进色板。
- 大面积保持暗,彩色只用在关键词、交互焦点、强调线上。

## 动效手感
- 全片共用同一组缓动:飞行与出现用「快起慢停」,UI 交互用「轻弹簧」(不过度回弹)。
- 3D 演示中卡片可以极缓慢地漂移/微转,「静而不死」;角度克制(一般 8–20°)。
- 闪光少而大,不要满屏碎粒子;标题不要太粗、不要明显发光。

## 文字
- 关键词大而清楚(横屏中文 120–220px),越大越不用粗;中文思源黑体(Noto Sans SC 真字重),英文/数字 Inter 或 Space Grotesk,代码和网址用等宽。
- **字一出现不能被挡**;一段的字出齐后留够时间读完再切。

## 音效
- 镜头飞行一声呼啸;大字落定低沉「咚」;逐字出现细碎滴答;UI 按钮按下「咔哒」;标签弹出轻「啵」;结果揭示清脆提示音。
- 克制,永远在人声下面;不做背景音乐。

## 不要做的事
- 不要整片都是 UI(上一次用户因此要求回退),也不要整片都是平面文字。
- 不要两种段落之间硬切。
- 不要让 UI 卡片自带另一套配色。
- 不要像 PPT 那样每段同一种版式。
