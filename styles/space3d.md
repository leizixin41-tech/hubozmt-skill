# 风格档案:space3d(3D 空间版,默认)

来源:用户 2026-10-24 定的新方向 + 拆解 4 个胡泊 Hubo 参考视频的文字与排版(样张在 `styles/_ref_hubo/`)。
取代 `fusion`(「卡片立起来」的 3D/UI 段被真 3D 摄像机取代)。引擎:`engine/web/hz_3d.js` + `hz_type.js`,30 帧。
第一期样片:`episodes/2026-10-24_dsh-pet-3d/03_scene.html`(写法照它抄)。

## 气质一句话
像 AE 里**摄像机绑空对象**:所有素材、界面、文字都是 3D 图层,**按远近摆放表示主次**;摄像机在图层之间**缓动 + 急停**地飞,焦点永远落在当前重点上,其他层自然虚掉。纸面、暗角、颗粒、窗光让画面有「拍出来」的质感。

## 空间与摄像机
- **每一镜先想清楚重点是什么**,再决定素材/文字放哪、机位从哪个角度看。
- **分层(远近)**:前景(z +200~+500)= 当前要读的字、标签;中景(z 0)= 主素材、界面;背景(z −300~−2000)= 次要素材、巨大淡字(ghost)。**同一平面上不要堆多个重点**。
- **案例段(规范 v2)**:前景 = 可交互控件(终端、代码块、pills、浏览器)和标题;中景 = 真实截图窗;背景 = 弱化 UI。主视觉必须是截图/UI,文字只做标注(`规范/`)。
- **运镜手感**:缓动起步 + 急停到位(`hz.ease.stop`);飞行 0.4–0.7 秒,飞行中略拉远(弧线),到位后可以有很慢的推近/环绕漂移(drift),让画面不死。
- **角度**:观点、情绪段可轻微**仰视**(pitch 5–10°)+ 侧转(yaw 8–16°),文字因此带透视;**教学、演示、界面操作段用平视**(pitch 0–2°,yaw ≤10°),景深调浅(ap 6–8),保证界面字清楚。
- **景深(必须)**:焦点 = 当前重点所在的深度;离焦越远越虚。**移焦(rack focus)**代替切镜:机位不动,只把焦点从 A 层推到 B 层(适合「A 在做……它也跟着……」这类前后呼应,也适合口播很密、来不及飞的时候)。
- 撞击、重音:镜头震动(`sp.shake`)+ 一帧级故障(`sp.glitch`),全片 ≤3 次。
- 布景:每段一个「布景原点」,相邻布景横向相隔约 3000、深度错开几百,镜头在布景之间飞。上一个布景的东西飞出画面就不用管。

## 文字(从胡泊视频拆出来的那套)
### 字体角色
| 角色 | 字体 | 用在 |
|---|---|---|
| 主标题 / 关键词 | 思源宋体 900(`.f-song`),副句 700(`.f-song7`) | 每段主词,大、重、有书卷气 |
| 情绪 / 动作词 | 得意黑斜体(`.f-smiley`) | 「Q弹」「甩出去」「更绝的是」——速度感,每段最多一处 |
| 英文品牌 / 数字 | Bricolage 800 窄体斜切(`.f-brand`)/ `.f-num` | `dsh-pet`、`AI`、`3,600+`,常用主色 |
| 英文小字 | Instrument Serif 斜体(`.f-sub`) | 中文关键词下面一行英文翻译/注释(胡泊招牌做法) |
| 等宽 | JetBrains Mono(`.f-mono` `.tagm`) | 命令、仓库名、全大写小标签 `GITHUB STARS` |
| 手写 | 霞鹜文楷(`.f-wk`) | 宠物/角色说话、「演示」小注 |

### 排版
- 文字块**左对齐**,钉在当前机位的屏幕左侧(用 `TS(时刻, 屏幕x, 屏幕y, 前移距离, …)`),比素材更靠近镜头 → 字清楚、素材略虚,层级一眼就清楚。
- 一屏最多 3 级:主词(120–270px)/ 副句(60–100px)/ 英文小字或标签(30–50px);主词与副句字号比 ≥ 1.5。
- 背景放一个和本段相关的**巨大淡字**(opacity 0.07,远到被景深虚掉),只做氛围。
- 纸片标签(`T.chip`,浅底/黑底 + 圆点 + 粗宋)用来贴分类、属性、步骤名。

### 出现 → 强调 → 消失
| | 手法 | 什么时候用 |
|---|---|---|
| 出现 | `type` 打字机 + 粗光标 | 引导句、命令、「它会记住」这类「说出来」的话 |
| | `rise` 逐字上浮去虚 | 默认主词 |
| | `drop` 放大砸下 | 重音词、数字结论 |
| | `slide` 带运动模糊滑入急停 | 转折词「更绝的是」「最离谱的是」 |
| | `scatter` 散字显影 | 纸片标签里的字 |
| | `T.pop` 整块从虚到实 + 轻弹 | 卡片、图片、纸片 |
| 强调 | `T.marker` 黄色荧光笔从左扫到右(压在字的下半) | 最常用,一段一处 |
| | `T.tape` 黑胶带擦过、字反白 | 结论词、反转词 |
| | `T.under` 下划线 / `T.strike` 删除线 / `T.box` 描框 / `T.brackets` 角标 | 链接感、否定、点名、引用 |
| | 关键词换主色/强调色 | 和上面的手法二选一,不叠三层 |
| 消失 | `T.out` blur 虚化 / slide 运动模糊滑走 | 和镜头飞行同时发生 |

## 后期质感
暖灰纸背景(中间提亮)、暗角、胶片颗粒(每帧换位)、两道斜窗光、边缘轻微色差、飞行时运动模糊。都在 `hz.space()` 里,默认就开。

## 色板(默认,可按项目换主色)
`--c-bg #E4E1DB` 纸 · `--c-ink #141414` 墨 · `--c-mute #8A867E` · `--c-main` 项目主色 · `--c-accent #FF5A1F` 橙 · `--c-mark #FFE14A` 荧光黄 · `--c-card #F8F7F4` · `--c-line #DAD6CE`。
暗场(转折、「最离谱的是」)用 `hz.k.dark(sp, [[t0, t1]])`(屏幕空间满幅淡入淡出),字改用纸色/荧光黄。**不要在世界空间铺黑底板**:大板飞行中会被视野裁剪隐藏,露出纸底竖缝(见 `规范/02` 第六节)。

## 硬规矩(检查器会查)
- 文字出场前整块隐藏(引擎已处理);完整出现后**至少 0.6 秒**才能被飞镜甩出画面或虚掉。口播太密时:让字提前出、或用移焦代替飞镜。
- 文字不贴边(30px),不互相重叠,不被素材挡住。
